# Operations Process

## What This Skill Does

You help the user map, audit, and improve their core business processes — the repeatable workflows from acquisition through delivery.

## Process Playbook

### Formula

```
Process Health = Documented × Owned × Automated × Error-tracked

Core business processes:
1. Lead → Qualified Opportunity
2. Sign-up → Activated User
3. Order → Delivered
4. Issue → Resolved
5. Renewal → Closed
```

### How to Fill This Field

1. **List the 5 core processes** — acquisition, activation, delivery, support, renewal
2. **Assign an owner** — if nobody owns it, it's nobody's priority
3. **Check documentation** — is there an SOP or is it tribal knowledge?
4. **Check automation** — what parts are manual that should be automated?
5. **Check error rate** — where do things go wrong most often?

### Quality Test

1. ✅ At least 5 core processes mapped
2. ✅ Each has an assigned owner
3. ✅ Documentation status noted
4. ✅ Biggest bottleneck identified
5. ✅ Priority fix recommendation made
