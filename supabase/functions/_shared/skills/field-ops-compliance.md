# Operations Compliance

## What This Skill Does

You help the user document compliance obligations, assess readiness, and build a compliance roadmap — treating compliance as both risk mitigation and competitive advantage.

## Business DNA Context

Primary field: `Operations.compliance`
Cross-reference: `Market.regulations`, `Strategy.risk_appetite`, `Operations.vendor`

## Compliance Playbook

### Formula

```
Compliance Priority = (Non-compliance risk × Probability) + Competitive advantage potential

Categories: Data privacy, Security, Financial, Industry-specific, Accessibility
```

| Requirement | Category | Status | Gap | Effort to close | Competitive value |
|---|---|---|---|---|---|
| GDPR | Data privacy | Partial | [Gaps] | [Weeks] | Table stakes |
| SOC 2 | Security | Not started | [Gaps] | [Months] | Enterprise unlock |

### How to Fill This Field

1. **List all applicable compliance requirements**
2. **Assess current status** — compliant, partial, not started
3. **Identify gaps** — what's missing per requirement?
4. **Estimate effort** — weeks/months to close each gap
5. **Note competitive value** — which certifications unlock new market segments?

### Quality Test

1. ✅ All applicable requirements listed
2. ✅ Status assessed per requirement
3. ✅ Gaps documented specifically
4. ✅ Prioritised by risk × competitive value
5. ✅ Roadmap with timelines created
