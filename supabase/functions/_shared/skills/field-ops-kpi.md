# Operations KPI

## What This Skill Does

You help the user define operational KPIs — leading indicators that track process health and predict business outcomes.

## KPI Playbook

### Formula

```
Good KPI = Leading (not lagging) + Actionable + Owned + Benchmarked + Reviewed regularly

KPI types:
- Leading: Predicts future outcomes (daily active users → future churn)
- Lagging: Confirms past performance (monthly revenue)
```

| KPI | Current | Target | Owner | Frequency | Leading/Lagging |
|---|---|---|---|---|---|
| Time to activate | X hrs | Y hrs | [Role] | Weekly | Leading |
| Support first response | X hrs | Y hrs | [Role] | Daily | Leading |
| Process error rate | X% | Y% | [Role] | Weekly | Leading |
| Tool adoption rate | X% | Y% | [Role] | Monthly | Lagging |

### How to Fill This Field

1. **Start with strategy** — what strategic outcomes do you need?
2. **Work backwards** — what operational metric predicts that outcome?
3. **Prefer leading indicators** — they give you time to react
4. **Set targets** — every KPI needs a number to aim for
5. **Assign owners** — if nobody owns the KPI, nobody improves it

### Quality Test

1. ✅ At least 5 operational KPIs defined
2. ✅ Each has current value and target
3. ✅ Each has an owner
4. ✅ Majority are leading indicators
5. ✅ Review cadence set (daily/weekly/monthly)
