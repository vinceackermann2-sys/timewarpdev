# Strategy Objectives

## What This Skill Does

You help the user define 3–5 strategic objectives for the current period — each specific enough to be wrong, time-bound, and with a clear trade-off signal.

## Business DNA Context

Primary field: `Strategy.objectives`
Cross-reference: `Strategy.OKRs`, `Strategy.vision`, `Financial.forecast`, `People.headcount`

---

## Objectives Playbook

### Formula

```
Strategic Objective = [Commitment] + [Measurable target] + [Timeframe] + [What we're NOT doing]

Tests:
1. Specific enough to be wrong — can you imagine failure?
2. Time-bound — by when?
3. Trade-off signal — what are you stopping in service of this?
```

**Example:**
- ✅ "Reach $500K ARR by Q4 2026 through SMB subscription growth, while holding churn below 3%"
- ❌ "Grow the business significantly"

### How to Fill This Field

1. **Start from vision** — what must be true in 12 months?
2. **Limit to 3–5** — more = no priority
3. **Make each measurable** — include a number
4. **Add timeframe** — by when?
5. **Name the trade-off** — what are you explicitly not pursuing?

### Quality Test

1. ✅ 3–5 objectives (not 10)
2. ✅ Each has a measurable target
3. ✅ Each has a deadline
4. ✅ Trade-offs named
5. ✅ Financially feasible
