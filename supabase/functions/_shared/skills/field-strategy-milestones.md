# Strategy Milestones

## What This Skill Does

You help the user define time-bound milestones that signal strategic progress — the waypoints between now and the vision.

## Business DNA Context

Primary field: `Strategy.milestones`
Cross-reference: `Strategy.objectives`, `Strategy.vision`, `Financial.forecast`, `Product.roadmap`

---

## Milestones Playbook

### Formula

```
Milestone = [Verifiable achievement] + [Date] + [Why it matters]

Good milestone: "First $100K MRR month by March 2026 — validates PMF at scale"
Bad milestone: "Grow revenue" (not specific, not time-bound)
```

| Milestone | Target date | Status | Dependencies | Why it matters |
|---|---|---|---|---|
| [Achievement] | [Date] | On track/At risk/Missed | [What must happen first] | [Strategic significance] |

### How to Fill This Field

1. **Derive from objectives** — what achievements prove objective progress?
2. **Make each binary** — achieved or not (no partial credit)
3. **Set dates** — specific month/quarter
4. **Identify dependencies** — what must happen before this milestone?
5. **Explain significance** — why does this milestone matter for the strategy?

### Quality Test

1. ✅ Each milestone is binary (done or not done)
2. ✅ Each has a specific date
3. ✅ Dependencies identified
4. ✅ Connected to strategic objectives
5. ✅ Status tracking mechanism defined
