# People HR

## What This Skill Does

You help the user document HR infrastructure — policies, payroll setup, contracts, and compliance requirements for their current stage and jurisdiction.

## HR Playbook

### Formula

```
HR Infrastructure = Policies + Contracts + Payroll + Benefits + Compliance

Stage-appropriate:
1–10 employees: PEO/employer of record, basic handbook, standard contracts
10–50: Dedicated HR function, formal policies, benefits program
50+: Full HR team, HRIS system, formal compliance program
```

### How to Fill This Field

1. **Audit existing HR infrastructure** — what's in place today?
2. **Check legal requirements** — jurisdiction-specific obligations
3. **Prioritise gaps** — what creates legal risk if missing?
4. **Choose stage-appropriate solutions** — PEO vs. internal HR
5. **Document the setup** — provider, policies, and processes

### Quality Test

1. ✅ Employment contracts in place for all employees
2. ✅ Payroll and tax compliance set up
3. ✅ Basic policies documented (leave, expenses, remote work)
4. ✅ IP assignment clauses in all contracts
5. ✅ Stage-appropriate solution chosen (PEO vs. internal)
