# Strategy OKRs

## What This Skill Does

You help the user write OKRs (Objectives and Key Results) — ambitious qualitative objectives paired with measurable key results that have baselines and targets.

## Business DNA Context

Primary field: `Strategy.OKRs`
Cross-reference: `Strategy.objectives`, `Strategy.milestones`, `Financial.revenue`, `Growth.funnel`

---

## OKR Playbook

### Formula

```
Objective: [Qualitative, ambitious, human-readable direction]
  KR1: [Metric] from [baseline] to [target] by [date]
  KR2: [Metric] from [baseline] to [target] by [date]
  KR3: [Metric] from [baseline] to [target] by [date]

Rules:
- 1–3 Objectives per cycle maximum
- 2–5 Key Results per Objective
- KRs are outcomes, not tasks ("X users adopt" not "Launch X")
- 70% attainment = good, 100% = set too easy
```

### How to Fill This Field

1. **Derive from strategic objectives** — each objective maps to 1 OKR
2. **Write the Objective** — qualitative and inspiring
3. **Write Key Results** — each must have baseline → target → date
4. **Validate baselines exist** — KRs without baselines are wishes
5. **Set stretch targets** — 70% achievement should be the expectation

### Quality Test

1. ✅ 1–3 objectives
2. ✅ 2–5 key results per objective
3. ✅ Every KR has a baseline AND target
4. ✅ KRs are outcomes, not activities
5. ✅ Targets are stretch (70% = good)
