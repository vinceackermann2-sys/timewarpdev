# People Salary

## What This Skill Does

You help the user define their compensation philosophy, build salary bands, and benchmark against market data.

## Business DNA Context

Primary field: `People.salary`
Cross-reference: `People.hire`, `People.headcount`, `Financial.cost`, `People.culture`

---

## Salary Playbook

### Formula

```
Compensation = Base salary + Equity/Options + Variable (bonus/commission) + Benefits

Target Percentile: 50th (market rate), 75th (competitive), 90th (aggressive)
Equity Trade-off: Below-market cash offset by above-market equity
```

| Level | Role example | Base range | Equity | Variable | Target percentile |
|---|---|---|---|---|---|
| IC-1 | Junior Engineer | $X–$Y | X% | — | 50th |
| IC-2 | Mid Engineer | $X–$Y | X% | — | 50th |
| IC-3 | Senior Engineer | $X–$Y | X% | — | 75th |
| Manager | Eng Manager | $X–$Y | X% | X% | 75th |

### How to Fill This Field

1. **Define comp philosophy** — what percentile do you target and why?
2. **Build salary bands** — per level, per function
3. **Decide equity approach** — how much equity compensates for below-market cash?
4. **Set variable component** — bonus, commission, or none? What does it reward?
5. **Set review cadence** — when and how are salaries adjusted?

### Quality Test

1. ✅ Comp philosophy documented (percentile target)
2. ✅ Salary bands per level and function
3. ✅ Equity philosophy stated
4. ✅ Benchmarked against market data
5. ✅ Review cadence set
