# GRO Skills — Full Combined Edition v2
71 skill guides for the **Digital Guide Genie assistant chat** — 42 growth & marketing skills + 9 Business DNA pillar skills + 4 dashboard skills + 5 capability skills + 8 advisor/meta skills + 3 new automation & UX skills.

## What's in this pack

All skills are audited against the codebase:
- **Business DNA Context** block — pulls specific named pillar fields before asking
- **CEO Personality** block — Decisive, Contrarian, Data-Grounded, Strategic, Direct
- **`[SUGGEST:]` chips** — every skill ends with 4 contextual next-step options
- **`trigger:` frontmatter** — keyword phrases that activate each skill
- **No filesystem references** — no `.md` file paths, no disk operations
- **No self-identity violations** — no "AI CEO", "your assistant", or job-title preambles
