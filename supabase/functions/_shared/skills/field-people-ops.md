# People Ops

## What This Skill Does

You help the user design people operations — performance review cycles, onboarding processes, learning & development programs, and the recurring rituals that develop and retain talent.

Review Cycle = Frequency × Quality of feedback × Action taken

### How to Fill This Field

1. **Audit existing processes** — what's in place for each category?
2. **Check onboarding** — is there a structured first-90-days plan?
3. **Check performance reviews** — how often? What format? Is feedback actionable?
4. **Check development** — do employees have growth paths?
5. **Check offboarding** — are exit interviews conducted? Are insights captured?

### Quality Test

1. ✅ Onboarding process documented with milestones
2. ✅ Performance review cycle defined
3. ✅ 1-on-1 cadence set
4. ✅ Development paths exist for key roles
5. ✅ Offboarding includes exit interviews
