# Operations Workflow

## What This Skill Does

You help the user design and optimise workflows — how work moves between people, systems, and teams.

## Workflow Playbook

### Formula

```
Workflow = [Trigger] → [Steps] → [Handoffs] → [Output] → [QA Check]

Workflow Efficiency = Value-add time ÷ Total elapsed time
(Most workflows are <20% value-add — the rest is waiting, handoffs, and rework)
```

### How to Fill This Field

1. **Map each workflow** — trigger, steps, who does what, handoffs
2. **Identify wait states** — where does work sit waiting for someone?
3. **Count handoffs** — every handoff is a failure point
4. **Measure elapsed time vs. work time** — the gap is waste
5. **Identify automation candidates** — steps that are repetitive and rule-based

### Quality Test

1. ✅ At least 3 key workflows mapped end-to-end
2. ✅ Handoffs identified with responsible parties
3. ✅ Wait states/bottlenecks flagged
4. ✅ Automation opportunities noted
5. ✅ Owner assigned per workflow
