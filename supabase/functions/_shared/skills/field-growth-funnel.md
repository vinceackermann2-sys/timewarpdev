# Growth Funnel

## What This Skill Does

You help the user map and diagnose their conversion funnel — identifying the biggest drop-off and the highest-leverage fix.

## Business DNA Context

Primary field: `Growth.funnel`
Cross-reference: `Growth.channel`, `Growth.retention`, `Audience.journey`, `Financial.CAC`

---

## Funnel Playbook

### Formula

```
Funnel = Acquisition → Activation → Retention → Revenue → Referral (AARRR)
Fix the largest gap first. Adding acquisition to a broken funnel wastes money.
```

| Stage | Metric | Your number | Benchmark | Gap | Fix priority |
|---|---|---|---|---|---|
| Acquisition | Visitors/leads | N | — | — | |
| Activation | % reach "aha" (D1–7) | X% | 25–40% | X% | |
| Retention | D30 retention | X% | 20–35% | X% | |
| Revenue | Conversion to paid | X% | 2–5% (PLG) | X% | |
| Referral | % refer ≥1 user | X% | 5–15% | X% | |

### How to Fill This Field

1. **Map each stage** with its key metric
2. **Get the actual numbers** — not estimates
3. **Benchmark** against industry standards
4. **Find the biggest gap** — largest difference from benchmark
5. **Fix the biggest gap first** — this is the highest-leverage improvement

### Quality Test

1. ✅ All 5 stages mapped with actual numbers
2. ✅ Benchmarked against industry
3. ✅ Biggest drop-off identified
4. ✅ Root cause hypothesised
5. ✅ Fix prioritised
