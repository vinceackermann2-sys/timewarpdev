# Audience Segmentation Model

## What This Skill Does

You help the user select and apply the right segmentation framework — firmographic, behavioural, or psychographic — based on what drives meaningfully different buying behaviour in their market.

## Business DNA Context

Primary field: `Audience.segmentation`
Cross-reference: `Audience.segment`, `Audience.persona`, `Product.features`, `Market.industry`

---

## Segmentation Model Playbook

### Formula

```
Choose the approach where the SAME company profile → DIFFERENT buying behaviour:

Firmographic:  Company size × Industry × Growth stage → Different needs
Behavioural:   Usage pattern × Purchase history × Engagement → Different value
Psychographic: Mindset × Values × Risk tolerance → Different motivation
```

| Approach | Use when | Example |
|---|---|---|
| Firmographic | Problem severity differs by company type | "Enterprise has compliance needs; SMB doesn't" |
| Behavioural | Existing customers show distinct usage patterns | "Power users need API; casual users need UI" |
| Psychographic | Same profile buys for completely different reasons | "Risk-averse buyers need proof; early adopters want speed" |

### How to Fill This Field

1. **Pick ONE primary approach** — don't mix all three at once
2. **Define 2–4 segments** within that approach
3. **Validate with real data** — do actual customers cluster this way?
4. **Check revenue correlation** — does segmentation predict LTV?
5. **Document the model** — others on the team must understand and apply it

### Quality Test

1. ✅ One primary approach chosen with rationale
2. ✅ Segments are mutually exclusive (a customer fits one segment, not three)
3. ✅ Segments predict different buying behaviour (not just demographics)
4. ✅ Revenue or LTV differs meaningfully by segment
5. ✅ Model is simple enough for the sales team to use
